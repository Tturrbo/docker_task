# Скрипт для конвертации аллелей формата allel1 allel2 в формат REF ALT
### Команды для предобработки файла FP_SNPs.txt
Первая `awk` команда приведет первую строку в формат VCF и удалит координаты GRCh37. Вторая команда удалит варианты с X-хромосомы(23-я хромосома):
```
awk 'BEGIN{FS=OFS="\t"} NR==1{print "#CHROM", "POS", "ID", "allele1", "allele2"; next} {print "chr"$2, $4, "rs"$1, $5, $6}' FP_SNPs.txt | \
awk 'BEGIN{FS=OFS="\t"} $1 != "chr23"' > FP_SNPs_10k_GB38_twoAllelsFormat.tsv
```
В результате создатся файл с названием FP_SNPs_10k_GB38_twoAllelsFormat.tsv, который будет подаваться на вход в скрипт.

### Посмотреть обязательные аргументы для запуска сркипта можно с помощью команды:
```
ref_alt.py --help
```
`--fasta` принимает на вход путь до файла референсного генома формата `.fa` или `.fasta` \
`--input` принимает на вход путь до предобработанного файла с аллелями(FP_SNPs_10k_GB38_twoAllelsFormat.tsv) формата `.tsv` \
`--output` название итого файла(например, output.txt или output.tsv) \
Все три аргмента обязательно должны быть прописаны при запуске скрипта. В итоге команда запуска выглядит так:
```
ref_alt.py --fasta GRCh38.d1.vd1.fa --input FP_SNPs_10k_GB38_twoAllelsFormat.tsv --output output.txt
```
Описание работы скрипта:
```
1. Провекра на формат поданных аргументов. В случае неправильного формата файла или его отсутствия скрипт выдаст ошибку.
2. Референсный геном индексируется и делится на 25 файлов по хромосомам chr[1-3], X, Y, M. Каждый файл проиндексируется и переносится в папку $CHROM_DIR
3. Далее каждый файл из папки $CHROM_DIR остается октрытым до конца сверки аллелей с референсным нуклеотидом. Если референсный нуклеотид = нуклеотиду аллелил, то данная аллель считается референсной(REF), а другая - альтернативной(ALT).В случае если ни один аллель не является референсным оба нуклеотила аллеля1 и 2 записываются в колонку ALT через запятую.
4. После завершения определения референсного аллеля создается итоговый файл и указывается время всего скрипта.
```
По итогу работы сркипта получается табулированный файл по типу: `#CHROM<TAB>POS<TAB>ID<TAB>REF<TAB>ALT`
Команда для поиска неопределившихся алеллей:
```
awk 'BEGIN{FS=OFS="\t"} NR==1 || $5 ~ /,/' [output_file_name].tsv > [unknown_allels_file_name].tsv

```
